# 📖 مشروع القرآن الكريم بصيغة Markdown المفهرسة

مشروع متكامل ومؤتمت لجلب القرآن الكريم كاملاً بدقة متناهية بالرسم العثماني المعتمد، وتوليد ملفات `Markdown` (`.md`) منفصلة لكل سورة من سور القرآن الـ 114، مع فهرسة شاملة وروابط تنقل تفاعلية.

---

## 🌟 مميزات المشروع

- **نص قرآني كامل وموثوق**: 114 سورة كاملة تشمل جميع الآيات الـ 6,236 بالرسم العثماني ومضبوطة بالشكل التام مع أرقام الآيات بنمط الأقواس المصحفية `﴿١﴾`.
- **ملف منفصل لكل سورة**: كل سورة في ملف مستقل مرتب ومسلسل برقم ثلاثي الخانات (مثل: `001_سورة_الفاتحة.md` إلى `114_سورة_الناس.md`) ليظهر بالترتيب الصحيح في جميع برامج استعراض الملفات.
- **فهرس رئيسي شامل (`000_الفهرس.md`)**:
  - إحصائيات القرآن الكريم (عدد السور، الآيات، المكي والمدني، الأجزاء، الأحزاب، السجدات).
  - جدول تفصيلي لكل السور مع روابط مباشرة وتحديد مكان النزول وترتيب النزول وعدد الآيات والصفحات.
  - فهرس مرتب حسب الأجزاء الـ 30 مع روابط السور في كل جزء.
- **تنسيق ثنائي داخل كل سورة**:
  1. **نص متواصل (قراءة المصحف)**: لقراءة السورة كاملة متتابعة.
  2. **آيات مفصلة ومرقمة**: كل آية مستقلة مع أرقام الجزء والصفحة وعلامة سجدة التلاوة `۩` إن وجدت، مما يسهل التدبر والبحث.
- **بيانات وصفية متوافقة (YAML Frontmatter)**: في رأس كل ملف سورة، متوافقة مع Obsidian وNotion وJekyll وHugo وAstro وQuartz.
- **روابط تنقل سريعة**: في أسفل كل سورة رابط للسورة السابقة، والفهرس الرئيسي، والسورة التالية.
- **تخزين محلي مؤقت (Offline Cache)**: يتم حفظ نسخة JSON محلية في مجلد `data/` لتوليد الملفات في ثوانٍ دون الحاجة لإعادة الاتصال بالإنترنت في كل مرة.
- **بدون أي مكتبات خارجية (Zero Dependencies)**: يعمل المشروع على بايثون القياسي مباشرة.

```text
│   ├── 001_سورة_الفاتحة.md

│   ├── 003_سورة_آل_عمران.md
│   ├── ...
│   └── 114_سورة_الناس.md
├── fetch_quran.py                  # سكربت بايثون الرئيسي لجلب وتوليد الملفات
└── README.md                       # دليل المشروع والتوثيق
```

## 🚀 طريقة التشغيل

### تشغيل السكربت عبر سطر الأوامر (CMD أو PowerShell)
```bash
python fetch_quran.py
```

### خيارات متقدمة
```bash
# تحديد مجلد إخراج مخصص:
python fetch_quran.py --output-dir "مجلدي"

# حفظ نسخة محلية للتخزين المؤقت (اختياري للعمل دون اتصال بالإنترنت):
python fetch_quran.py --cache-file "data/quran.json"
```
