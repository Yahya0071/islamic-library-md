# 📖 المكتبة الإسلامية بصيغة Markdown المفهرسة

مستودع متكامل يضم نصوص **القرآن الكريم كاملاً** و**كتاب الأربعون النووية** في الحديث النبوي الشريف، بصيغة `Markdown` (`.md`) عالية الجودة والدقة، مع فهرسة شاملة وروابط تنقل تفاعلية.

---

## 📑 محتويات المستودع

### 1. 📖 قسم القرآن الكريم ([القران/](القران/000_الفهرس.md))
- **114 سورة كاملة**: تشمل جميع الآيات الـ 6,236 بالرسم العثماني المعتمد وفق مجمع الملك فهد، مضبوطة بالشكل التام مع أرقام الآيات بنمط الأقواس المصحفية `﴿١﴾`.
- **ملف منفصل لكل سورة**: كل سورة في ملف مستقل مرتب ومسلسل برقم ثلاثي الخانات (مثل: `001_سورة_الفاتحة.md` إلى `114_سورة_الناس.md`) لضمان الترتيب الصحيح.
- **الفهرس العام الشامل ([000_الفهرس.md](القران/000_الفهرس.md))**:
  - إحصائيات القرآن الكريم (السور، الآيات، المكي والمدني، الأجزاء، الأحزاب، السجدات).
  - جدول تفصيلي لكل السور مع روابط مباشرة وتحديد مكان وترتيب النزول والأجزاء والصفحات.
  - فهرس مرتب حسب الأجزاء الـ 30 مع روابط السور في كل جزء.
- **تنسيق ثنائي داخل كل سورة**:
  1. **نص متواصل (قراءة المصحف)**: لقراءة السورة كاملة متتابعة.
  2. **آيات مفصلة ومرقمة**: كل آية مستقلة مع أرقام الجزء والصفحة وسجدات التلاوة `۩`.
- **بيانات وصفية متوافقة (YAML Frontmatter)**: متوافقة مع برامج إدارة المعرفة مثل Obsidian وNotion وQuartz ومولدات المواقع الثابتة.
- **سكربت الجلب والأتمتة ([fetch_quran.py](fetch_quran.py))**: سكربت بايثون قائم بذاته بالكامل لجلب وتحديث نصوص المصحف دون أي مكتبات خارجية.

### 2. 📜 قسم الحديث الشريف ([الحديث/](الحديث/كتاب%20الأربعون%20النووية.md))
- **[كتاب الأربعون النووية](الحديث/كتاب%20الأربعون%20النووية.md)**: للإمام الحافظ محيي الدين أبي زكريا يحيى بن شرف النووي (631 - 676 هـ).
- **مقدمة المصنف**: منقحة ومحررة بالكامل من فواصل الصفحات والرموز المشوشة لتستقيم القراءة البلاغية الأصلية لكلام الإمام.
- **الأحاديث الـ 42 كاملة**:
  - **فهرس تفاعلي شامل**: جدول في صدر الكتاب يضم رقم الحديث وموضوعه والصحابي الراوي والتخريج مع روابط تنقل سريعة.
  - **بطاقة الحديث**: توضح الراوي والتخريج والمصدر وحكم الحديث.
  - **صندوق نص الحديث**: نص الحديث مشكولاً بدقة مع إبراز كلام النبي ﷺ وتخريجه.
  - **الشرح والفوائد المستنبطة**: شرح مستفيض وفوائد عقدية وفقهية لكل حديث داخل قوائم قابلة للطي والفتح (`<details>`) لقراءة مريحة بدون تشتيت.
  - **شريط تنقل تفاعلي**: روابط في أسفل كل حديث للانتقال المباشر بين (الحديث السابق | فهرس الأحاديث | الحديث التالي).

## 🚀 طريقة تشغيل سكربت القرآن

المشروع يعتمد كلياً على مكتبات بايثون القياسية دون الحاجة لتثبيت أي حزم خارجية:

```bash
# توليد ملفات القرآن الكريم والفهرس:
python fetch_quran.py

# خيارات متقدمة (تحديد مجلد مخصص أو تخزين كاش محلي):
python fetch_quran.py --output-dir "القران" --cache-file "data/quran.json"
```
